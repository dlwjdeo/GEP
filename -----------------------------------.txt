사과는 일정시간마다 생성 -> 시간이 지날수록 재생성 시간이 길어짐
돌도끼 기본 제공
------------------------------------------------------------
사과 바리에이션 => 사과, 썩은 사과, 랜덤 사과(체력 감소, 체력 증가 등) / 요리된 사과

식물 = 랜덤 성장

나무를 캠 -> 나무 장작

나무를 배면 사과랑 나뭇가지를 떨구자 -> level 

맨손으로 나무를 캘 수 있음 but 시간이 오래걸림

철광석은 일정 시간마다 자연 스폰

성장중인 나무 + 양동이 => 완전히 성장한 나무
------------------------------------------------------------
나무 + 철광석 = 철도끼 -> 나무를 캘 수 있음
나무 + 나무 = 양동이 -> 비어있음, 물이 차있음
나무 + 식물 = 낚시대 -> 낚시 가능

양동이 + 나무 = 완전 성장

사과 + 불 = 요리된 사과

낚시 => 랜덤 아이템 (사과(10), 물고기(40), 식물(40), 철광석(10) 등) = 확률 동적 할당 
ex) 철광석이 안나오면 철광석 확률 +5%, 나오면 초기화
------------------------------------------------------------
로켓 => 나무(50) or 철광석(200) or 식물(10) 로 수리 가능 => 2000 min

E키 => 낚시, 벌목(도끼 + 나무 상호작용), 들기(떨어진 아이템, 식물), 물주기(채워진 양동이 + 성장중인 나무), 수리, 
요리(사과, 물고기 + 불) -> UI로 표시 (들기, 물주기, 철도끼 만들기)

인터렉터블 리스트(들수있음 -> 사용가능) => 장작, 식물, 사과(바리에이션), 물고기, 철광석, 나무, 로켓

Equipment(낚시대, 도끼, 양동이)
